# Cards

## Purpose
Карточки группируют связанный контент и действия в ограниченном контейнере.

## When to use
- Контент с заголовком, описанием и действиями (превью темы, политика).
- Сетки превью компонентов (Этап 10).
- Блоки, кликающиеся как единое целое.

## Variants
| Variant | Радиус | Использование |
|---|---|---|
| Default | `rounded-xl` (16px) | обычные контейнеры |
| Elevated | `rounded-2xl` (20px) | выделенные блоки, CTA |

## Tokens
- Фон: `surface` / `surface-container` (по слою).
- Граница: `outline` (или `--c42-outline` напрямую).
- Текст: `on-surface` / `on-surface-variant`.

## Rules
- Внутренние отступы: `gap-4` или `gap-6`.
- Превью цветов внутри карточки — только Swatch-компонент, не сырые div.
- Hover: лёгкое усиление тени (без scale на данных аудита).
- Не фиксировать высоту — контент определяет высоту.
- Статус экспорта в карточке темы — бейдж из ролей (`error` для blocked).

## Do
```tsx
<Card className="rounded-xl p-6">
    <CardTitle>Тема «Лесная»</CardTitle>
    <CardDescription>gov-aa · 8 режимов · экспорт разрешён</CardDescription>
</Card>
```

## Don't
- Хардкод `bg-white` / `bg-black`.
- Обрезать контент фикс-высотой.
- Карточка для простого текста без визуальной границы не нужна.
