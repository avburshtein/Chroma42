# Pattern: аудит-панель (Этап 9)

Панель показывает, **почему** тема собрана такой: каждую пару, тона, порог и
статус. Это главная ценность Chroma42 — честная проверяемость.

## Состав
1. **Таблица проверок** — строка на каждую пару каждого режима:
   пара, режим, фактический контраст, требуемый порог, статус.
2. **Цветовая индикация строк** — только роли темы:
   pass → обычные роли; warn → приглушённые (`on-surface-muted`); fail →
   `error` / `error-container`.
3. **Статус режима** — «Экспорт разрешён» / «Экспорт заблокирован в строгом
   режиме»: строго по `audit.summary.exportAllowed`, без интерпретации UI.
4. **Скачивание** — `accessibility-report.json` и `.md`
   (`buildMarkdownReport`), кнопка «Скопировать CSS» рядом с экспортом.

## Правила
- Статусы не редактируются и не фильтруются UI так, чтобы скрыть fail;
  фильтрация только в пользу видимости проблем (по умолчанию fail сверху).
- Числа контраста — с 2 знаками: `4.52:1` против `4.50:1` — видно запас.
- Пары с alpha (`surface-glass`) помечаются «проверено на подложке
  background» — предупреждение методологии, не ошибка.
- Для каждой строки доступна расшифровка: какой тон выбрал солвер и почему
  (`solvedTone`/`reason`).
- Панель сама рендерится текущей темой — она живое превью экспорта.

## Don't
- Не приукрашивать статусы (fail → warn → скрыть — запрещено,
  см. `anti-patterns.md`).
- Не дублировать расчёты контраста в UI: числа только из отчёта движка.
- Не скрывать предупреждения reduced-transparency.
