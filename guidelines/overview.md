# Product guidelines — Chroma42

## Product
Chroma42 — инженерный генератор цветовых токенов с проверяемой методологией
доступности (WCAG 2.2 AA, EN 301 549, ГОСТ). UI обязан показывать, **почему**
тема собралась именно такой: каждая пара, тон и статус аудита — видимы.

## Дизайн-система
База — UX42 Design System (проект `ux42studio`): Material Design 3 foundation,
шрифты Poppins (display) + Inter (body), семантические цветовые роли M3.

Ключевое отличие от ux42studio: **источник истины для цветов — движок
Chroma42**. Экспорт `tokens.css` (8 режимов) + `tailwind.css` (`@theme inline`)
генерируется `exportTailwindTheme()`; UI рендерит собственную тему через те же
токены, что выдаёт пользователю.

## Read first
1. `setup.md` — подключение токенов движка, провайдеров, маппинг
2. `tokens.md` — роли, 8 режимов, типографика
3. `components/` — правила компонентов
4. `patterns/` — паттерны продукта (режимы, аудит-панель)
5. `anti-patterns.md` — запреты
6. `component-audit.md` — что взято из ux42studio и что добавлено

## Core principles
- **Engine-first.** Цвета UI задаёт собранная тема, а не дизайнер. Если цвета
  нет в движке — сначала токен, потом UI.
- **Честный аудит.** Статусы pass/warn/fail показываются как есть; шлюз
  экспорта (`audit.summary.exportAllowed`) — истина, UI его не обходит.
- Все цвета через токены (`--c42-*` через M3-адаптер) — ноль хардкодов.
- 8 режимов переключаются атрибутом `data-theme` (см. `patterns/mode-switching.md`).
- Взаимодействия по M3: один filled-баттон на секцию, verb-first подписи,
  `cn()` + `cva` + Radix-примитивы.

## Definition of done
- Layout работает на mobile и desktop.
- hover / focus-visible / active / disabled у всех интерактивных элементов.
- Контраст самого UI ≥ WCAG AA во всех 8 режимах — инструмент про доступность
  не имеет права не проходить собственный аудит.
- Ни одного хардкода цветов, размеров, радиусов, теней.
- Статусы аудита не скрываются и не «сглаживаются».
- Все варианты компонентов задокументированы в `components/`.
