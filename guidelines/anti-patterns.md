# Anti-patterns

## Never do
- Не хардкодить цвета, размеры, радиусы, тени — даже «временные» значения.
- Не использовать инлайн-стили (`style={{ ... }}`).
- Не создавать кастомные кнопки/инпуты/карточки/диалоги, когда есть ui-кит.
- Не добавлять вторую UI-библиотеку или дизайн-систему.
- Не дублировать значения токенов в локальном CSS.
- **Не приукрашивать аудит:** fail нельзя показывать как warn, скрывать или
  «сглаживать»; шлюз экспорта (`exportAllowed`) — единственная истина.
- Не показывать непрошедшие строгий режим пары как «экспортированные».
- Не использовать dropdown при ≤2 опциях — radio или segmented control.
- Не убирать зарезервированное место под helper/error в полях (CLS).

## Prefer instead
- Токены движка (`--c42-*` / M3-адаптер) и семантические роли.
- Один filled-баттон на экран/секцию; verb-first подписи («Собрать тему»,
  «Скопировать CSS», «Скачать отчёт»).
- Честные пустые / loading / error / success состояния.
- Dropdown только для 3+ опций.

## Component-specific prohibitions
- **Button:** не ставить два filled рядом с равным весом; фокус — `ring-2`
  с `primary` и offset (канон ux42studio Button).
- **Input/Textarea/Select:** фокус — `outline-2` + `outline-offset-[-2px]` +
  `border-transparent` (канон ux42studio); всегда внутри `Field`.
- **Dialog:** видимый close, обработка `Escape`, корректный focus trap.
- **Swatch / AuditTable:** статусные цвета — только роли темы
  (`error`, `on-surface-muted`, …), не сырой hex из данных.
- **ThemeProvider:** режим — полный (8 значений), не булев light/dark.
